# Ski-Hi Stampede Pitch Site

Private pitch deliverable from SeatMaxx for the Ski-Hi Stampede (skihistampede.com) rodeo. Shared via staging URL for Ski-Hi review.

**Not for public distribution.** Robots are disallowed; the staging site sets `noindex` on every page until explicit launch.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Railway auto-builds and deploys from the linked GitHub branch on push.
