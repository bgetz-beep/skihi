## If you want to grab Facebook imagery later

Open `https://www.facebook.com/skihistampedeinc/` in a browser logged in (or not; try without first) and save manually:

1. **Cover photo**: top banner image. Right-click, "Save image as", drop into `public/images/raw/social/fb-cover.jpg`.
2. **Profile photo**: circular logo top-left. Save as `fb-profile.jpg`.
3. **Pinned post image** (if any): save as `fb-pinned.jpg`.
4. **Recent event photos**: last 5-10 photo posts. Save sequentially as `fb-recent-01.jpg`, `fb-recent-02.jpg`, etc.

Then update this file with a list of what you saved and move on.
